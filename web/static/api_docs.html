开放接口文档

供外部系统（脚本、第三方平台等）通过 API Key 调用：以 OpenAI 兼容格式对话（可带知识库与工具能力）、上传文档自动切片入库、查询与删除知识库文档。

1. 概述

所有开放接口以 /open/v1/ 为前缀，使用 API Key 认证，与登录态（JWT）无关。上传的文档会被自动提取文本、切片并写入 Key 所属用户的向量知识库，随即可在对话中被检索。

2. 获取 API Key

在控制台点击右上角用户名打开 个人资料，在「我的 API Key」区域点击 创建 API Key。创建成功后会显示一次完整 Key（形如 sk-xxxxxxxx...），请立即保存——之后只能看到前缀。

创建时需选择调用模式，决定对话接口 /open/v1/chat/completions 的行为：Agent 完整链路（默认）——走服务端 Agent（固定问答、知识库检索、工具调用，数据按 Key 所属用户隔离）；纯模型代理——把请求原样转发给当前启用的模型，不带知识库与工具。两种模式不影响文档管理接口。

调用时在请求头中携带 Key，两种方式任选其一：

X-API-Key: sk-xxxxxxxx
# 或
Authorization: Bearer sk-xxxxxxxx

3. 接口列表

POST/open/v1/chat/completions　对话补全（OpenAI 兼容）

与 OpenAI /v1/chat/completions 协议兼容，可直接使用官方 SDK。行为由 Key 的调用模式决定：

Key 模式行为
Agent 完整链路固定问答短路 → 知识库检索 → 工具调用 → 回答。对话历史由服务端按 Key 所属用户维护，messages 只需传本轮 user 消息（历史字段会被忽略）
纯模型代理messages 与采样参数原样转发给当前启用的模型，无知识库、无工具、无系统提示注入，完全无状态

model 参数会被忽略（统一使用控制台当前启用的模型）。支持 stream: true 流式输出（SSE，以 data: [DONE] 结尾）。已透传的采样参数：temperature / top_p / max_tokens / presence_penalty / frequency_penalty。

请求体：

{
  "messages": [{"role": "user", "content": "根据销售报告，华东区利润多少？"}],
  "stream": false,
  "temperature": 0.7
}

成功响应 200（非流式）：

{
  "id": "chatcmpl-xxxx",
  "object": "chat.completion",
  "model": "deepseek-chat",
  "choices": [{"index": 0, "message": {"role": "assistant", "content": "…"}, "finish_reason": "stop"}],
  "usage": {"prompt_tokens": 0, "completion_tokens": 0, "total_tokens": 0}
}

curl 示例：

curl -X POST "{BASE}/open/v1/chat/completions" \
  -H "X-API-Key: sk-xxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{"messages":[{"role":"user","content":"你好"}]}'

Python（OpenAI SDK）示例：

from openai import OpenAI

client = OpenAI(base_url="{BASE}/open/v1", api_key="sk-xxxxxxxx")
resp = client.chat.completions.create(
    model="any",   # 服务端忽略此参数
    messages=[{"role": "user", "content": "你好"}],
    stream=False,  # True 时 resp 为流式增量
)
print(resp.choices[0].message.content)

POST/open/v1/upload　上传文档并入库

以 multipart/form-data 提交文件，字段名为 file。服务端提取文本、切片并向量化入库。

约束说明
支持格式.md / .txt / .pdf / .docx / .doc / .xlsx / .xls
大小上限50 MB（单文件）
同名文件覆盖同名旧文件；如需重新入库请先删除旧文档

成功响应 200：

{
  "filename": "产品手册.pdf",
  "chunks": 42,          // 本次切片数量
  "total": 138           // 该用户知识库当前总片段数
}

curl 示例：

curl -X POST "{BASE}/open/v1/upload" \
  -H "X-API-Key: sk-xxxxxxxx" \
  -F "file=@产品手册.pdf"

Python 示例：

import requests

resp = requests.post(
    "{BASE}/open/v1/upload",
    headers={"X-API-Key": "sk-xxxxxxxx"},
    files={"file": open("产品手册.pdf", "rb")},
    timeout=300,
)
print(resp.json())

GET/open/v1/docs　列出已入库文档

成功响应 200：

{
  "docs": ["产品手册.pdf", "会议纪要.docx"],
  "total": 2,      // 文档个数
  "chunks": 138    // 知识库总片段数
}

curl 示例：

curl "{BASE}/open/v1/docs" -H "X-API-Key: sk-xxxxxxxx"

DELETE/open/v1/docs/{filename}　删除文档及其向量片段

filename 需 URL 编码（中文文件名尤其注意）。

成功响应 200：

{
  "deleted": "产品手册.pdf",
  "total": 96
}

curl 示例：

curl -X DELETE "{BASE}/open/v1/docs/%E4%BA%A7%E5%93%81%E6%89%8B%E5%86%8C.pdf" \
  -H "X-API-Key: sk-xxxxxxxx"

4. 错误码

HTTP 状态含义常见原因
401认证失败未携带 Key / Key 无效 / Key 已被禁用或删除
400请求错误文件格式不受支持；对话接口 messages 缺失或无有效 user 消息
404资源不存在删除的文档不存在
413文件过大超过 50MB 上限
500入库失败文档内容无法提取（如加密 PDF、空文档）
502上游模型失败对话接口：服务端未配置模型，或上游 API 调用出错

错误响应格式：/open/v1/chat/completions 返回 OpenAI 风格 {"error": {"message": "...", "type": "..."}}（官方 SDK 可直接解析）；其余接口返回 {"detail": "错误描述"}。

5. 常见问题

上传后对话中检索不到？

上传成功即已入库，直接向 Agent 提问相关内容即可（Agent 会自动检索知识库）。若检索不到，检查文档内容是否确实包含相关表述，或在控制台「向量片段」页确认切片结果。

Key 泄露了怎么办？

在控制台右上角「个人资料 → 我的 API Key」中删除该 Key 即可立即失效，再创建新 Key。
